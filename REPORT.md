# Проверка программы

Проверка выполнена 20 ноября 2026 года. Python 3.12.14, Apache Maven 3.9.9, maven-dependency-plugin 3.8.1, Graphviz 16.1.1. POM-файлы загружались из Maven Central с помощью urllib и разбирались через ElementTree.

## Тестовые репозитории

Примеры запуска и сообщения об ошибках: [reports/demo.txt](reports/demo.txt). Скрипт `scripts/demo.py` воспроизводит ее.

| Случай | Проверяемый результат |
|---|---|
| Ромб A → B,C; B,C → D | D присутствует один раз; порядок D,B,C,A |
| A → B → C → A, C → D | Граф сохраняет цикл; order сообщает A → B → C → A и код 1 |
| A → A | Нет бесконечного обхода; линейный порядок невозможен |
| Изолированный A | Одна вершина, порядок A |
| Глубина 0 | Только A |
| Глубина 1 | A, B, C без раскрытия их зависимостей |
| Фильтр B | B и его исходящая ветка исключаются; D доступен через C |
| Длинный путь к D раньше короткого | При глубине 3 появляются E и F по короткому пути A → D → E → F |

Тесты также проверяют цепочку из 2001 вершины, пространства имен XML, parent POM, управляемые версии и кэш. Отдельно проверяются ошибки в XML и JSON, ссылки на отсутствующие пакеты, параметры запуска и работа без Graphviz.

## Реальные пакеты и визуализация

Для каждого пакета создан отдельный проект `demo:comparison:1` с одной зависимостью. Команды Maven: `dependency:resolve`, `dependency:tree -Dscope=runtime -DoutputType=text`, `dependency:tree -Dscope=runtime -DoutputType=dot`, с зафиксированной версией плагина 3.8.1. POM, журналы Maven и результаты сравнения находятся в `reports/real`. В сохраненных журналах абсолютный путь к папке проекта заменен на `<project>`; остальные строки оставлены без изменений.

| Пакет | Программа: вершины / ребра | Maven после удаления технического корня | Совпадение |
|---|---:|---:|---|
| junit:junit:4.13.2 | 2 / 1 | 2 / 1 | Да |
| org.apache.commons:commons-text:1.12.0 | 2 / 1 | 2 / 1 | Да |
| com.fasterxml.jackson.core:jackson-databind:2.17.2 | 3 / 2 | 3 / 2 | Да |

Сравниваются как множества вершин (`comparison.json`), так и ребер (`edge-comparison.json`). Из имен Maven удаляются тип jar и scope; искусственный корень demo:comparison удаляется из сравнения. На изображениях Maven он сохранен, поэтому там на один узел больше. Дополнительная вершина относится к проекту сравнения. Направление остальных связей совпадает.

## Порядок загрузки

Режим order строит порядок «сначала зависимости, затем потребитель»; каждый пакет выводится один раз. Maven скачивает готовые артефакты, поэтому сетевой порядок не обязан удовлетворять этому условию. Он зависит от кэша и параллельных запросов. Порядок завершения скачивания JAR взят из строк `Downloaded from central` журнала `resolve.log`.

| Пакет | Порядок программы | Наблюдение Maven |
|---|---|---|
| JUnit | hamcrest-core 1.3 → junit 4.13.2 | junit → hamcrest-core |
| Commons Text | commons-lang3 3.14.0 → commons-text 1.12.0 | Скачан только commons-lang3; commons-text уже был загружен как зависимость плагина при предыдущем запуске |
| Jackson Databind | jackson-annotations → jackson-core → jackson-databind (все 2.17.2) | jackson-databind → jackson-annotations → jackson-core |

Приложение рассчитывает порядок обработки зависимостей, а Maven может скачивать несколько файлов одновременно. Поэтому порядок отличается. Для Commons Text в данном запуске нельзя восстановить полный сетевой порядок из-за кэша; это явно видно в сохраненных журналах. Циклическому графу нельзя назначить порядок с каждой зависимостью раньше потребителя, поэтому приложение сообщает ошибку вместо произвольного списка.

## Источники правил Maven

- [Dependency mechanism](https://maven.apache.org/guides/introduction/introduction-to-dependency-mechanism.html): scope, optional, управление версиями и конфликты.
- [POM Reference](https://maven.apache.org/pom.html): свойства и наследование.
- [Dependency Plugin tree](https://maven.apache.org/plugins/maven-dependency-plugin/tree-mojo.html): штатный экспорт дерева в DOT.

Ограничения перечислены в README. На пакетах с exclusions, профилями и конфликтующими версиями результат может отличаться от Maven.
