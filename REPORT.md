# Отчет о проверке

Проверка выполнена 20 ноября 2026 года. Python 3.12.14, Apache Maven 3.9.9, maven-dependency-plugin 3.8.1, Graphviz 16.1.1. Получение данных приложением выполнено напрямую из https://repo.maven.apache.org/maven2 через urllib и ElementTree стандартной библиотеки Python.

## Тестовые репозитории

Полная демонстрация CLI и кодов завершения: [reports/demo.txt](reports/demo.txt). Скрипт `scripts/demo.py` воспроизводит ее.

| Случай | Проверяемый результат |
|---|---|
| Ромб A → B,C; B,C → D | D присутствует один раз; порядок D,B,C,A |
| A → B → C → A, C → D | Граф сохраняет цикл; order сообщает A → B → C → A и код 1 |
| A → A | Нет бесконечного обхода; линейный порядок невозможен |
| Изолированный A | Одна вершина, порядок A |
| Глубина 0 | Только A |
| Глубина 1 | A, B, C без раскрытия их зависимостей |
| Фильтр B | B и его исходящая ветка исключаются; D доступен через C |
| Длинный путь к D раньше короткого | При глубине 3 появляются E и F по короткому пути A → D → E → F |

Модульные тесты дополнительно проверяют цепочку из 2001 вершины без рекурсии, XML namespaces, parent и управляемые версии, кэш, malformed XML/JSON, отсутствующие ссылки, параметры, экранирование DOT и отсутствие Graphviz.

## Реальные пакеты и визуализация

Для каждого пакета создан отдельный проект `demo:comparison:1` с одной зависимостью. Команды Maven: `dependency:resolve`, `dependency:tree -Dscope=runtime -DoutputType=text`, `dependency:tree -Dscope=runtime -DoutputType=dot`, с зафиксированной версией плагина 3.8.1. Точные POM, журналы, деревья, DOT и результаты сравнения сохранены в подкаталогах `reports/real`.

| Пакет | Наши вершины / ребра | Maven после удаления технического корня | Совпадение |
|---|---:|---:|---|
| junit:junit:4.13.2 | 2 / 1 | 2 / 1 | Да |
| org.apache.commons:commons-text:1.12.0 | 2 / 1 | 2 / 1 | Да |
| com.fasterxml.jackson.core:jackson-databind:2.17.2 | 3 / 2 | 3 / 2 | Да |

Сравниваются как множества вершин (`comparison.json`), так и ребер (`edge-comparison.json`). Из имен Maven удаляются тип jar и scope; искусственный корень demo:comparison удаляется из сравнения. На изображениях Maven он сохранен, поэтому там на один узел больше. Это различие постановки сравнения, а не лишняя зависимость библиотеки. Стили рисунков различаются; направление ребер совпадает.

## Порядок загрузки

Наш режим order строит детерминированный порядок «сначала зависимости, затем потребитель»; каждый пакет выводится один раз. Maven скачивает готовые артефакты, поэтому сетевой порядок не обязан удовлетворять этому условию. Он зависит от кэша и параллельных запросов. Сравниваем наблюдаемый порядок завершения загрузки JAR в строках `Downloaded from central` журнала `resolve.log`, а не выдаем порядок дерева Maven за порядок скачивания.

| Пакет | Наш порядок | Наблюдение Maven |
|---|---|---|
| JUnit | hamcrest-core 1.3 → junit 4.13.2 | junit → hamcrest-core |
| Commons Text | commons-lang3 3.14.0 → commons-text 1.12.0 | Скачан только commons-lang3; commons-text уже был загружен как зависимость плагина при предыдущем запуске |
| Jackson Databind | jackson-annotations → jackson-core → jackson-databind (все 2.17.2) | jackson-databind → jackson-annotations → jackson-core |

Эти расхождения ожидаемы: приложение рассчитывает порядок обработки графа, а Maven выполняет сетевые передачи. Для Commons Text в данном запуске нельзя восстановить полный сетевой порядок из-за кэша; это явно видно в сохраненных журналах. Циклическому графу нельзя назначить порядок с каждой зависимостью раньше потребителя, поэтому приложение сообщает ошибку вместо произвольного списка.

## Источники правил Maven

- [Dependency mechanism](https://maven.apache.org/guides/introduction/introduction-to-dependency-mechanism.html): scope, optional, управление версиями и конфликты.
- [POM Reference](https://maven.apache.org/pom.html): свойства и наследование.
- [Dependency Plugin tree](https://maven.apache.org/plugins/maven-dependency-plugin/tree-mojo.html): штатный экспорт дерева в DOT.

Ограничения учебной модели перечислены в README. На проектах с exclusions, профилями и конфликтующими версиями возможны расхождения с Maven, даже если эти три примера совпадают.
