# Граф зависимостей Maven

Программа строит граф зависимостей Java-пакета по его POM-файлу. Написана на Python. Для получения зависимостей используются urllib и ElementTree из стандартной библиотеки.

## Запуск

Нужен Python 3.10 или новее. Для создания изображений нужен [Graphviz](https://graphviz.org/download/), команда `dot` должна быть доступна через PATH. Дополнительные Python-библиотеки не требуются.

Команды выполняются из папки проекта:

```text
python -m pip install -e .
python -m mavengraph --package junit:junit:4.13.2 --repository https://repo.maven.apache.org/maven2
```

В Windows можно использовать `./run.ps1` вместо `python -m mavengraph`. Если Python установлен в нестандартной папке, путь к `python.exe` задается переменной `MAVENGRAPH_PYTHON` или в файле `.local/python.txt`. Этот файл содержит одну строку с путем и не включается в Git.

## Параметры

| Параметр | Назначение |
|---|---|
| `--package` | Пакет в формате groupId:artifactId:version или буквенное имя в тестовом режиме |
| `--repository` | URL Maven-репозитория или путь к тестовому JSON |
| `--test-mode` | Чтение зависимостей из тестового файла |
| `--max-depth` | Максимальная глубина, по умолчанию 10; 0 означает только исходный пакет |
| `--filter` | Подстрока для исключения пакетов по artifactId; регистр учитывается |
| `--mode` | Режим вывода, по умолчанию graph |
| `--output` | Путь к изображению SVG или PNG, по умолчанию build/graph.svg |
| `--dot` | Путь к программе dot, если ее нет в PATH |
| `--show` | Открыть изображение после создания, используется с режимом image |

Режимы вывода:

| Режим | Результат |
|---|---|
| `config` | Значения параметров |
| `direct` | Прямые зависимости, включая test, provided и optional |
| `graph` | Граф в формате JSON |
| `order` | Порядок обработки: зависимости раньше использующих их пакетов |
| `dot` | Текст графа на языке Graphviz |
| `image` | Изображение графа |

В режиме direct глубина и фильтр не применяются. В остальных режимах анализа строится граф compile/runtime-зависимостей без optional.

## Тестовый репозиторий

Файл содержит имена пакетов и списки их зависимостей:

```json
{
  "A": ["B", "C"],
  "B": ["D"],
  "C": ["D"],
  "D": []
}
```

Имена состоят из больших латинских букв. Для каждого упомянутого пакета нужна отдельная запись, даже если у него нет зависимостей.

```text
python -m mavengraph --test-mode --package A --repository examples/diamond.json
python -m mavengraph --test-mode --package A --repository examples/diamond.json --max-depth 1
python -m mavengraph --test-mode --package A --repository examples/diamond.json --filter B
python -m mavengraph --test-mode --package A --repository examples/diamond.json --mode order
```

Для последней команды результат: D, B, C, A. В папке examples есть ромб зависимостей, цикл, петля, изолированная вершина и граф с несколькими путями к одной вершине.

## Алгоритм

Граф строится обходом DFS без рекурсии, с помощью стека. Для каждой вершины запоминается минимальная найденная глубина. Если позже найден более короткий путь, ее зависимости рассматриваются повторно. На границе глубины новые POM не загружаются.

Циклы сохраняются в графе, но не приводят к бесконечному обходу. Для режима order используется отдельный итеративный DFS с проверкой циклов. Если цикл есть, программа выводит его путь и сообщает, что порядок построить нельзя. При ограниченной глубине порядок относится только к полученному графу.

Фильтр исключает пакет и переходы через него. Потомки могут остаться в графе, если к ним есть другой путь. Исключение исходного пакета считается ошибкой.

## Изображения

```text
python -m mavengraph --test-mode --package A --repository examples/cycle.json --mode image --output build/cycle.svg --show
python -m mavengraph --package junit:junit:4.13.2 --repository https://repo.maven.apache.org/maven2 --mode image --output build/junit.png --show
```

Рядом с изображением сохраняется DOT-файл. Стрелка A → B означает, что A зависит от B. Исходный пакет выделен зеленым цветом. Если Graphviz не найден, DOT остается доступным, а программа выводит сообщение об ошибке.

Готовые примеры для JUnit, Commons Text и Jackson Databind находятся в `reports/real`. Файлы `graph.*` созданы приложением, `maven.*` — по выводу Maven. Изображения тестовых графов находятся в `reports/test`.

## Проверка

```text
python -m unittest discover -s tests -v
python scripts/demo.py
```

Первая команда запускает тесты. Вторая записывает примеры работы и ошибок в `reports/demo.txt`.

Коды завершения: 0 — успех, 1 — ошибка получения данных или обработки графа, 2 — неправильные параметры. Проверяются формат имени, адрес или путь к репозиторию, тестовый режим, глубина и фильтр.

Для повторения сравнения с Maven:

```text
python scripts/compare.py --mvn mvn
python scripts/render_examples.py --dot dot
```

Для compare нужны JDK и Maven. Скрипт использует кэш `build/maven-cache`. Само приложение Maven не вызывает. Результаты приведены в [отчете](REPORT.md).

## Ограничения

Поддерживаются фиксированные release-версии, parent POM, свойства и dependencyManagement, включая BOM imports. Не реализованы профили, exclusions, выбор версии при конфликтах, применение управления версиями корня ко всему транзитивному графу, relocation и настройки Maven. Classifier и type не образуют отдельные вершины. Репозитории внутри POM и timestamped SNAPSHOT metadata не обрабатываются.

Диапазоны версий и неразрешенные свойства вызывают ошибку. Сложные случаи наследования POM и BOM могут обрабатываться иначе, чем в Maven. При глубине 0 существование реального пакета не проверяется, поскольку запрос к репозиторию не выполняется.

## Этапы работы

1. Параметры командной строки и проверка ошибок.
2. Получение прямых зависимостей из POM.
3. Обход графа, глубина, фильтр и тестовые файлы.
4. Порядок обработки зависимостей.
5. DOT, изображения и сравнение с Maven.

Для каждого этапа сохранен отдельный коммит. История доступна командой `git log --oneline --reverse`.
